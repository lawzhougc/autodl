控制已上线剧集的补集节奏。未上线的新集只要搜到 2160p 就自动下载（除非关闭下方开关）。
每批下载集数 集 — 一次最多连续追下几集

🎯 资源筛选偏好

决定「什么样的资源才值得下」。同时满足所有条件才会被选中；找不到符合的会跳过并在事件里提示。
首选清晰度 — 默认 4K
无首选时降级 — 不勾选时：找不到 4K 就停下来询问你，不会擅自下 1080p
语种 — 默认「英语优先」：意/德/法/俄等外语资源排在英语版之后。未标语种的资源视为英语
允许的格式
全都不勾 = 不限格式。勾了则只用勾选的格式（下载前用真实文件扩展名复核）
格式优先级 — 逗号分隔，靠前的优先；留空=不限
编码偏好 — 逗号分隔，靠前的优先；留空=不限
片源偏好 — 逗号分隔；留空=用默认权重(REMUX>BluRay>WEB)
优先 HDR/杜比视界 — 同条件下优先 HDR / Dolby Vision 版本
单集/单片大小 ~ GB — 0 表示不限。超出区间的资源直接跳过（防止整季包/超小低码率）
