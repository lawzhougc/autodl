⚙️ 下载节奏设置

控制已上线剧集的补集节奏。未上线的新集只要搜到 2160p 就自动下载（除非关闭下方开关）。
每批下载集数 集 — 一次最多连续追下几集
攒批间隔 小时 — 这批下完后隔多久再下下一批(0=不等待)
连续补集 — 关闭后每次只追最新已上线的一集
新集自动下载 — 关闭后只登记不下载，需手动确认
追剧搜索周期 小时 — 多久搜一次新集(0=每次 cron 都搜, 24=每天一次)
每轮提交上限 个任务 — 单次 cron 循环最多提交多少个

🎯 资源筛选偏好

决定「什么样的资源才值得下」。同时满足所有条件才会被选中；找不到符合的会跳过并在事件里提示。
首选清晰度 — 默认 4K
无首选时降级 — 不勾选时：找不到 4K 就停下来询问你，不会擅自下 1080p
语种 — 默认「英语优先」：意/德/法/俄等外语资源排在英语版之后。未标语种的资源视为英语
允许的格式
全都不勾 = 不限格式。勾了则只用勾选的格式（下载前用真实文件扩展名复核）
格式优先级 — 逗号分隔，靠前的优先；留空=不限
编码偏好 — 逗号分隔，靠前的优先；留空=不限
片源偏好 — 逗号分隔；留空=用默认权重(REMUX>BluRay>WEB)
优先 HDR/杜比视界 — 同条件下优先 HDR / Dolby Vision 版本
单集/单片大小 ~ GB — 0 表示不限。超出区间的资源直接跳过（防止整季包/超小低码率）

🔌 Jackett 服务配置

如未手动指定，系统会自动扫描 NAS 各存储卷及运行进程定位 ServerConfig.json 并提取 APIKey。若提示找不到或部署在其它机器，可在此手动指定。
服务地址 — 默认 http://127.0.0.1:9117
APIKey — 在 Jackett 控制台右上角可复制
配置文件路径 — 留空自动搜索所有 /vol*/@appdata/jackett/data/ 卷
